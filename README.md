# Tranh Kim Hoàng

A React Native (Expo SDK 57) app that walks a child through a Kim Hoàng woodblock: carve, roll black ink, stamp onto red paper, then color the print.

Code is in `kim-hoang-app/`. Product writing is in `kim-hoang-context/`.

## Run the app

See `kim-hoang-app/README.md`.
